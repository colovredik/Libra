# Libra — веб-сайт для читателей

Платформа для поиска, хранения и чтения электронных книг.

## Возможности
- Каталог книг с фильтрацией по жанру, автору, серии, объёму
- Поиск с выпадающими подсказками
- Регистрация и авторизация (хеширование паролей, сессии)
- Избранное с сохранением в базе данных
- Загрузка собственных книг с обложкой и PDF
- Чтение PDF через браузер
- Адаптивный интерфейс

## Стек
HTML, CSS, JavaScript, Node.js, Express, SQLite

## Запуск
1. Установите Node.js с nodejs.org
2. Склонируйте репозиторий:

git clone https://github.com/colovredik/libra

cd libra

npm install

node server.js

Сайт: http://localhost:3000

## Структура
- pages/ — HTML-страницы
- scripts/ — клиентский JavaScript
- styles/ — CSS
- server.js — серверная часть
- libra_data/ — база данных SQLite
